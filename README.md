# OilyGiant Oil Well Profit Prediction

## Project Overview

This project was developed for **OilyGiant**, an oil extraction company that needs to identify the most profitable region for developing **200 new oil wells**.

Using geological exploration data from three different regions, a **Linear Regression** model is trained to predict the oil reserve volume of new wells. The project then combines predictive modeling with **bootstrap risk analysis** to estimate expected profit, confidence intervals, and the probability of financial loss before making the final investment decision.

The objective is not only to maximize profit, but also to select the region with the best balance between **profitability and investment risk**.

---

## Business Problem

OilyGiant has a development budget of **100 million USD** to drill 200 new oil wells.

The company provided geological exploration data from three regions and wants to determine which region should receive the investment.

### Project Conditions

- Only **Linear Regression** may be used for model training.
- Each evaluation studies **500 candidate wells**.
- The **200 wells with the highest predicted reserves** are selected.
- The total drilling budget is **$100 million USD**.
- One thousand barrels generate **$4,500 USD** in revenue.
- Reserve volume is expressed in **thousand barrels**.
- Investment decisions must consider **bootstrap risk analysis**.
- Regions with a loss risk below **2.5%** are preferred.

# Methodology

The project follows four analytical stages.

## 1. Data Inspection

Each regional dataset was loaded and inspected before modeling.

### Findings

- No missing values were found.
- No duplicated rows were detected.
- The datasets required no preprocessing before model training.

Because the data were already clean, the workflow proceeded directly to predictive modeling.

---

## 2. Linear Regression Model

A custom function named `linear_regression_model_trainer()` was applied independently to each regional dataset.

### Function workflow

1. Split each dataset into training and validation sets.
2. Train a **Linear Regression** model.
3. Generate reserve predictions.
4. Store predictions and validation targets.
5. Calculate the mean reserve volume.
6. Compute the model RMSE.

The function returns a dictionary containing:

- Predictions
- Validation target
- Mean reserve volume
- RMSE

### Model Performance

| Region | Mean Reserve Volume | RMSE |
|---------|-------------------:|-----:|
| Region 0 | 92.50 | 37.68 |
| Region 1 | **68.83** | **0.89** |
| Region 2 | 95.00 | 40.15 |

### Training Conclusions

- Region 1 shows an exceptionally accurate model fit.
- Regions 0 and 2 exhibit very similar predictive behavior.
- Although Region 1 has the lowest average reserve volume, its predictions are considerably more reliable.

---

## 3. Profit Calculation

A second custom function, `calculate_profit()`, estimates the **real profit** generated by the wells selected by the predictive model.

### Inputs

- Output dictionary from `linear_regression_model_trainer()`
- Development budget
- Number of wells to select
- Revenue per thousand barrels

### Process

The function:

1. Converts predictions and targets into a Pandas DataFrame.
2. Sorts wells by predicted reserve volume.
3. Selects the best **200 wells**.
4. Calculates the real revenue using the true reserve values.
5. Subtracts the drilling budget to obtain net profit.

Additionally, it computes the **minimum reserve volume required per well** for the investment to become profitable.

### Initial Profit Estimation

| Region | Profit (Million USD) |
|---------|--------------------:|
| **Region 0** | **31.79** |
| Region 1 | 24.15 |
| Region 2 | 24.14 |

### Profit Analysis

The minimum reserve volume required for profitability is **111.1 thousand barrels per well**.

None of the three regions reaches this value on average, meaning profitability depends heavily on selecting the highest-performing wells rather than drilling randomly.

At this stage, **Region 0** appears to be the strongest candidate because it delivers the highest estimated profit.

---

## 4. Bootstrap Risk Analysis

Maximum profit alone is not sufficient for making a business decision.

To quantify uncertainty, the project applies **bootstrap resampling**.

### Bootstrap Procedure

For each region:

- 1,000 iterations
- Random samples of 500 wells (with replacement)
- Select the 200 wells with the highest predicted reserves
- Calculate the **real profit** using actual reserve values

The resulting distribution allows estimation of:

- Average profit
- Positive and negative outcomes
- Probability of loss
- 95% confidence interval

### Bootstrap Results

| Region | Positive | Negative | Loss Risk | 95% Confidence Interval (Million USD) |
|---------|---------:|---------:|----------:|--------------------------------------:|
| Region 0 | 926 | 74 | 7.40% | -1.60 to 9.18 |
| **Region 1** | **972** | **28** | **2.80%** | **-0.07 to 7.86** |
| Region 2 | 920 | 80 | 8.00% | -1.16 to 8.53 |

### Risk Analysis

- Region 1 has the lowest probability of financial loss.
- Regions 0 and 2 present nearly three times the downside risk.
- Region 1 also produces the most stable profit distribution across bootstrap simulations.

# Final Discussion

The project reveals an important distinction between **maximizing expected profit** and **making a risk-adjusted investment decision**.

### Stage 1 — Predictive Modeling

The Linear Regression model achieved dramatically different performances across regions.

Region 1 produced an RMSE of only **0.89**, suggesting that its geological features explain reserve volume with remarkable precision. Regions 0 and 2 generated substantially larger prediction errors despite having higher average reserve volumes.

### Stage 2 — Profit Maximization

Using the predicted reserve values to choose the best 200 wells, Region 0 generated the highest estimated profit (**$31.79 million**). If uncertainty were ignored, Region 0 would be the natural investment choice.

### Stage 3 — Uncertainty and Risk

Bootstrap analysis changed the business conclusion.

Although Region 0 offers greater expected profit, it also carries a **7.4% probability of loss**. Region 1 reduces that probability to **2.8%**, while maintaining consistently positive outcomes across most bootstrap samples.

The lower bound of Region 1's confidence interval corresponds to an estimated loss of only **$70,000**, representing approximately **0.07% of the total investment budget**. This downside exposure is dramatically smaller than the risks observed in the other regions.

---

# Final Recommendation

**Region 1 is recommended for investment.**

### Why Region 1?

- Lowest prediction error (RMSE = 0.89)
- Most reliable reserve estimates
- Highest number of profitable bootstrap outcomes
- Lowest probability of financial loss (2.8%)
- Narrowest confidence interval
- Best balance between profitability and investment stability

While Region 0 achieves the highest expected profit, Region 1 provides the strongest **risk-adjusted business decision**. This project demonstrates that predictive models should be complemented with uncertainty estimation before supporting high-cost investment strategies.
